# Chirag Dabhere’s portfolio

The home screen follows the opening composition of [Right Hemisphere](https://www.righthemisphere.studio/). Three words span the white canvas, the identity and navigation sit across the top, and a project index runs along the lower edge. The interlocking CD mark and the three technical drawings are original to this portfolio.

The root HTML, CSS and JavaScript run without a build step. Serve the repository root with `python3 -m http.server 4173 --bind 127.0.0.1`.

The URL fragment selects a section or a specific project. Browser Back and Forward revisit those views. On narrow screens the headline stacks and the project index stays within reach. A section can overflow internally for enlarged text. Reduced-motion preferences disable the headline ripple and entrance transitions.
